shellmate lets you type a question or a request in your shell prompt, press a shortcut, and get an answer or a command **in your prompt**. A suggested command is placed in your input line and is never run for you. It works in fish, zsh and bash.

:::note
shellmate is in early development. See <a href={docs('concepts/roadmap/')}>Status and roadmap</a> for what works today and what does not exist yet.
:::
